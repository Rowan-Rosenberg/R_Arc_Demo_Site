# R-Ark Demo Site

A modern, responsive website for R-Ark, a sustainable denim brand focused on custom denim products and eco-friendly materials.

## 🌟 Features

- **Custom Denim Builder**: Interactive tool for customizing jeans and jackets
- **Product Gallery**: Filterable showcase of denim products
- **Materials Showcase**: Detailed information about sustainable denim fabrics
- **Contact System**: Comprehensive contact form with multiple contact methods
- **Responsive Design**: Optimized for all devices and screen sizes
- **Sustainable Focus**: Highlighting eco-friendly practices and materials

## 🎨 Pages Overview

### Homepage (index.html)
- Brand story and introduction
- Company values and mission
- Links to all other sections

### Create Yours (pages/create-yours.html)
- Interactive denim customization tool
- Material selection (5 denim options)
- Style selection (jeans or jacket)
- Additional features panel with diagonal design element
- Real-time preview
- Step-by-step process with navigation

### Gallery (pages/gallery.html)
- 2D grid of product images
- Category filtering (All, Jeans, Jackets, Accessories)
- Hover effects with product details and pricing
- Responsive grid layout

### Materials (pages/materials.html)
- Detailed denim fabric information
- Categories: Organic Cotton, Recycled Denim, Premium Selvedge, Stretch Blend
- Sustainability badges and information
- Material specifications (weight, composition)
- Sustainability commitment section

### Contact (pages/contact.html)
- Contact information with phone number (+47 123 45 678)
- Comprehensive contact form with validation
- Multiple contact methods (phone, email, studio visits, live chat)
- FAQ section
- Social media links

## 📱 Responsive Design

The site is fully responsive with breakpoints:
- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: < 768px

## 🌱 Sustainability Focus

The site emphasizes R-Ark's commitment to sustainable fashion:
- Organic cotton materials
- Recycled denim options
- Water conservation practices
- Carbon neutral production
- Circular economy principles

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in a web browser
3. Navigate through the site using the main navigation

No build process required - the site uses vanilla HTML, CSS, and JavaScript.
